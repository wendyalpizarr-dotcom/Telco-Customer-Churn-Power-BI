# Dataset Source

## IBM Telco Customer Churn Dataset

This project uses the IBM Telco Customer Churn sample dataset published through Kaggle.

The dataset contains 7,043 customer records and 21 original fields covering:

- Customer demographics
- Account tenure
- Contract type
- Internet service
- Phone service
- Additional service subscriptions
- Payment method
- Monthly charges
- Total charges
- Customer churn status

## Source

Kaggle dataset:

https://www.kaggle.com/datasets/blastchar/telco-customer-churn

Original source:

IBM Sample Data Sets

## Target Variable

The original `Churn` field identifies whether a customer left the telecommunications company.

- Yes: Customer churned
- No: Customer remained with the company

## Usage

The dataset was used for educational and portfolio purposes to demonstrate:

- Data cleaning
- Data transformation
- DAX calculations
- Customer segmentation
- Churn analysis
- Business intelligence dashboard development
